# Example Story Universe

So the purpose of this vault is to serve as an example of a "blank" vault all setup to hold a story universe. 

To navigate, I recommend using the obsidian bookmarks (not the files). 

To make a story (novel, book, whatever) you need to make a folder with a name, and then make a .base file with that EXACT same name as the folder. There can be sub folders but the code isn't designed (aka has been tested with) sub stories. 

Use the "make scene" button on any note that you want to turn into a scene. This gives is the hidden property "notetoolbar: draft"

As of this writing, the Canvas Colors is design to have the name of the POV character for that scene in the "tags" field. Yes this is poor design. No I haven't cared enough to fix it (at least not yet). To change the characters (tags) and colors, you need to go outside of obsidian and open 00_Utility\QuickAdd-Scripts\canvasColorUpdater.js and change the colorMap near the top.
